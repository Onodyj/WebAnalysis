Core Service: AI Agent Automation for Digital Entrepreneurs

**Website Analysis Insights** is an integrated platform that deploys specialized AI Agents to automate complex business workflows across Print on Demand, KDP, Affiliate Marketing, and Digital Course businesses.

Our core agents—including **Website Analysis Insights**, **Creative Design**, and **Data & Reporting Analysis**—rely on minimal Google API scopes to perform essential functions such as reading scalable business metrics from BigQuery, writing synthesized insights back to Google Sheets, and securely delivering production-ready assets to Cloud Storage.

Quick deploy to GitHub Pages

  1. Create a new repository on GitHub (e.g. website-analysis).
  2. Commit this file (website_analysis.html) to the repository root or to a /docs folder.
  3. Enable GitHub Pages: Settings → Pages → Source: choose main branch / root (or /docs if used) → Save.
  4. After a short propagation (usually under 1–2 minutes) your site will be available at https://<your-username>.github.io/<repo-name>/.
